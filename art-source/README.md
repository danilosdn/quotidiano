# Arte original gerada

Os PNGs e WAVs desta entrega são gerados por `generate_assets.py` a partir de formas vetoriais rasterizadas em alta resolução e síntese procedural simples. As concept arts e a spritesheet mencionadas no briefing não estavam anexadas nesta conversa; por isso estes assets são uma direção visual original provisória, não uma reprodução das referências ausentes.
